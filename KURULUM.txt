ARICIMAP — PAROLA KURTARMA PAKETİ
==================================

Codespaces terminalinde:

cd /workspaces/ar-
unzip -o aricimap-yerlesim.zip
rm -f aricimap-yerlesim.zip KURULUM.txt
git add -A
git commit -m "Parola degistirme, kurtarma anahtari, kullanici yonetimi"
git push


ÖNEMLİ: KURTARMA ANAHTARINI ŞİMDİ TANIMLA
------------------------------------------
Render -> Environment -> Add Environment Variable

  Key   : ARICIMAP_RECOVERY_KEY
  Value : (uzun ve tahmin edilemez bir metin, örn. 30+ karakter)

Bu anahtar YALNIZCA sende olmalı. Yönetici parolasını unutursa tek
kurtarma yolu budur. Anahtar tanımlı değilse "Parolamı unuttum" ekranı
kapalı görünür ve kimse parolasını sıfırlayamaz.

Anahtarı bir yere yaz ve sakla. Kaybedersen Neon SQL konsolundan elle
müdahale etmek dışında yol kalmaz.


ÜÇ KURTARMA YOLU
----------------
1) Kullanıcı kendi parolasını değiştirir
   Hesap sekmesi -> Parola değiştir (mevcut parolayı bilmesi gerekir)

2) Yönetici, bir kullanıcının parolasını sıfırlar
   Yönetim -> Kullanıcılar -> Parola sıfırla
   Yeni parolayı kullanıcıya kendin iletirsin.

3) Kurtarma anahtarıyla sıfırlama (yönetici kendi parolasını unutursa)
   Giriş ekranı -> "Parolamı unuttum"
   Telefon + kurtarma anahtarı + yeni parola


SON ÇARE: YÖNETİCİ HESABI HİÇ KALMADIYSA
-----------------------------------------
Bir hesabı yöneticiye yükseltmek için (terminalden):

curl -X POST https://ar-3q6i.onrender.com/api/aricimap/recover/promote \
  -H 'Content-Type: application/json' \
  -d '{"recoveryKey":"ANAHTARIN","phone":"05XXXXXXXXX"}'


BU SÜRÜMDE AYRICA
-----------------
- Yönetim -> Kullanıcılar: tüm kayıtlı kişiler, rolleri ve bölgeleri
- Personelin bölgesi sonradan değiştirilebiliyor
- Parola değişince o kişinin tüm cihazlardaki oturumları kapanıyor
