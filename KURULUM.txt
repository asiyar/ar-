NEDEN "SON YAPTIKLARIN OLMAMIŞ" GÖRÜNÜYORDU
--------------------------------------------
Kod depoda ve sunucuda vardı. İki sebep:

1. APK eski. APK web dosyalarını derleme anında içine gömer; sunucudaki
   güncelleme APK'ya yansımaz. Her değişiklikten sonra APK yeniden
   üretilmeli: Actions -> Android Test APK -> Run workflow

2. Tarayıcı önbelleği. Artık script adreslerine sürüm damgası eklendi
   (aricimap-app.js?v=...), yeni sürüm her zaman iner.


BU SÜRÜMDE NE DEĞİŞTİ
---------------------
1. iframe kaldırıldı. Uygulama artık doğrudan ana sayfa.
   Bu ŞARTTI: Capacitor eklentileri iframe içinden erişilemiyor,
   dolayısıyla push bildirimi hiç çalışamazdı.
   Yan fayda: 410 KB React kabuğu artık üretilmiyor.

2. Push altyapısı hazır: cihaz jetonu kaydı, FCM gönderimi,
   bildirime dokununca ilgili sayfanın açılması.

3. Önbellek kırma: script adreslerinde sürüm damgası.


PUSH'U AÇMAK İÇİN YAPMAN GEREKENLER
------------------------------------
Bu kısmı ben yapamam; Firebase hesabı senin adına açılmalı.

ADIM 1 — Firebase projesi
  console.firebase.google.com -> Add project -> ad: aricimap
  Google Analytics'i kapatabilirsin.

ADIM 2 — Android uygulaması ekle
  Project settings -> Your apps -> Android
  Package name: com.arcadianstore.aricimap
  google-services.json dosyasını indir.

ADIM 3 — Dosyayı depoya koy
  google-services.json -> android/app/google-services.json
  DİKKAT: .gitignore bu dosyayı engelliyor olabilir. Engelliyorsa
  .gitignore icindeki "google-services.json" satirini sil.

ADIM 4 — Servis hesabı anahtarı
  Project settings -> Service accounts -> Generate new private key
  İnen JSON dosyasının TAMAMINI kopyala.

ADIM 5 — Render'a ekle
  Environment -> Add Environment Variable
  Key   : FCM_SERVICE_ACCOUNT
  Value : (adım 4'teki JSON'un tamamı, tek satır olarak)

ADIM 6 — APK'yı yeniden üret
  Actions -> Android Test APK -> Run workflow

KONTROL
  https://ar-3q6i.onrender.com/api/aricimap/push-status
  {"enabled":true} görüyorsan sunucu tarafı hazır.
  APK'yı kurup giriş yapınca telefon bildirim izni ister.
